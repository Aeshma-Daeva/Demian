# Archive

This directory holds useful but non-primary material.

Use it for history, context, and old design reasoning.
Do not start here when reloading the project.

For a guided chronological trail through the historical material, start with
[../RESEARCH_LINEAGE.md](/home/xenith/demian/docs/RESEARCH_LINEAGE.md). That
document explains which archive notes matter for each stage and how the older
ideas fed into the current Demian v1 synthesis.

## Layout

- `notes/`: research notebook and decision log
- `notes/PROJECT_DEMIAN.md`: retired compact snapshot from the earlier transformer-centric framing
- `plans/`: older implementation and research plans
- `plans/2026-04-24-native-controller-revision-blueprint.md`: retired native controller revision plan
- `plans/2026-04-29-v74-falsification-plan.md`: retired v7.4 falsification plan
- `plans/native-v2-memory-plan.md`: retired `demian_native_v2` memory experiment map
- `reference/`: broader conceptual or source-heavy material
- `superpowers/`: historical agent-oriented planning docs

Start with:
1. [../WORKING_STATE.md](/home/xenith/demian/docs/WORKING_STATE.md)
